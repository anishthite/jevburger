Ticket line and Jev

branch: none · worktree: jevburger · 2026-10-05 · ready-for-review · blast: medium

Summary

GoalWrite burger tickets and watch Jev work through the line.
Surfacesrc/engine/tickets.ts, src/main.tsx, vite.config.ts.
APIReuse /api/decide with a user or server key.
MobileTicket input and queue below the cooking scene.

Algorithm

  1. Parse supported burger aliases and modifiers; reject unsupported requests instead of silently ignoring them.
  2. Queue validated tickets FIFO; next ticket enters on completion without interrupting current cooking.
  3. Ignore a Jev result if mode or ticket changed while it was in flight.

UI layout

  1. Keep current order slip over grill.
  2. Ticket input and compact next-up queue below controls.
  3. Explicit real Jev key connection distinct from scripted demo.

Decisions

IDChoiceRationale
D-001Use deterministic local parsing for the fixed three-burger menu.Tickets should work without a model key; Jev remains responsible for cooking decisions.
D-002Keep real Jev opt-in rather than spending a key automatically.Each cooking move costs a provider request.
D-003Reject unsupported menu additions.A silently changed order makes correctness scoring misleading.
D-004Link ignored local .env to ../jevspresso/.env.Reuse the user's existing OpenRouter key without copying secret contents.
D-005Throttle Jev to one request per 1.3 seconds and stop after 50 moves per ticket.Make moves watchable and cap runaway cost.
