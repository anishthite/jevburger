Jev-only burger

branch: none · worktree: jevburger · 2026-10-06 · ready-for-review · blast: medium

Summary

GoalJev parses written tickets and cooks the whole burger, including patty timing.
SourceUser confirms patty frying, not fries; expand available ingredients.
SurfaceOrder schema, model parser, Jev-only UI, illustrated food.
MobileTicket input first, grill and top-down burger below.

API contract

POST /api/parse {text, key?} → {order, ...}; POST /api/decide {state, questions, key?} → {id}

Algorithm

  1. Ask Jev closed questions for recipe, doneness, cheese, and each available topping state; reject unsupported or multiple burgers.
  2. Construct a validated order and score exact layers from the normalized recipe.
  3. Ask Jev to move the burger through grill and assembly; recheck the latest legal action before delivery.

UI layout

  1. Write-ticket form at top; line of pending tickets.
  2. Single grill and top-down burger plate; move caption only.
  3. Automatic Jev progression; pause control for cost/errors.
