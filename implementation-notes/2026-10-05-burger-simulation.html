Burger simulation

branch: none · worktree: jevburger · 2026-10-05 · ready-for-review · blast: medium

Summary

GoalPlayable single-burger simulation controlled by Jev or a human.
SurfaceVite React UI and local Node-backed Jev endpoint.
SchemaClosed burger actions and immutable transition function.
MobileStacked ticket, station, and activity rail.

API contract

POST /api/decide {state,options,key?:{provider,key}} → {id:string}; GET /api/config → {configured:boolean}

Algorithm

  1. Derive legal moves from current state and cooking time.
  2. Describe only those moves to Jev; revalidate its choice against the latest state.
  3. Compute served correctness from recipe and finished stack.

UI layout

  1. Top navigation and order selection.
  2. Ticket, grill/assembly illustration, decision rail.
  3. Mobile stack in reading order with controls by the station.

Followups

  • Add scripted Jev eval runs after the core interaction is evaluated with a real key; current tests cover deterministic engine flows.
  • Replace local Vite middleware with an authenticated, rate-limited API before public deployment.

Reversibility

Local provider middleware can be replaced by a deployed server endpoint without changing the domain engine.

Definition of done

  • Legal moves tested; stale Jev decisions ignored.
  • Responsive UI; typecheck, test, build pass.
